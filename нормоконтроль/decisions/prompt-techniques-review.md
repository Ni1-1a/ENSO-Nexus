# Обзор промт-техник из @ai_prompt_eng («AI песочница инженера») — Этап 0-Б

Дата: 24.08.2026. Статус: **согласовано Никитой 24.08.2026** — приняты рекомендации по всем строкам А1–А19; безусловные части А16/А19 (узкие проверки, стабильный системный промпт, правила «двух адресов» и «последствия») включены. Вопрос второго прохода по 81 вложению канала остаётся открытым (см. decisions/open-questions.md).

## Как собрано и разобрано

- История канала выгружена **через публичное веб-зеркало t.me/s** (отступление от плана: my.telegram.org стабильно отдавал «ERROR» при создании приложения, MTProto-ключи получить не удалось; зеркало отдаёт те же данные без авторизации). Дамп: `_raw/telegram/ai_prompt_eng.jsonl`, 290 постов, id 1–358, скрипт дозагрузки `tools/telegram/fetch_via_web.py`.
- Вложения: 78 фото/видео скачаны (`_raw/telegram/media/`), **81 документ (PDF/DOCX) через зеркало недоступен** — опись в `media_manifest.jsonl`; добираются экспортом из Telegram Desktop. Анализ ниже сделан только по текстам постов; вложения не анализировались.
- Карантин соблюдён: текст постов обрабатывался как данные, инструкции из постов не исполнялись, ссылки не открывались, код не запускался; каждый приём пересказан своими словами. Детальные разборы: `scratchpad/этап0б/tg-1-179.md` и `tg-180-358.md` (по каждому кандидату — фильтры и цитаты-ориентиры).
- Фильтры из ТЗ: (1) тип задачи — агентная работа; (2) фактологичность — привязка к источнику; (3) формат — структурированный вывод; (4) совместимость с правилами Этапа 3 (обязательные `source.ntd`+`clause`, цитаты, «детерминированное — кодом», идемпотентность, `local_only`).

**Статистика:** 290 постов → 133 пустых/служебных/только медиа, 71 без приёмов (реклама, новости, анонсы), **86 кандидатов**: принято 58 (два поста слиты в одну строку), требует адаптации 19, отклонено 8, QUARANTINED 1. Примечательно: jailbreak-паттернов в канале нет — канал сам системно топит за источники и верификацию.
