Статусы:
- ЕСТЬ — требование раскрыто в ЗнП по существу;
- НЕПОЛНО — пункт упомянут, но содержания недостаточно для проектирования (нет чисел, перечней, характеристик);
- НЕТ — в ЗнП пункта нет вовсе;

Правила:
- Верни строку результата для КАЖДОГО пункта чек-листа, ни один не пропускай и не добавляй своих.

- Оценивай по существу, а не по совпадению заголовков: требование может быть раскрыто в другом разделе.
