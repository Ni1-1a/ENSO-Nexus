# Перенос Enso-nexus на Windows

Всё, что нужно, чтобы поднять эту же платформу на компьютере с Windows и увести
на него постоянный адрес `https://enso-nexus.com`. Папка лежит внутри самого
проекта, поэтому уезжает на Windows вместе с `git clone` — ничего копировать
отдельно не нужно.

## Коротко: что делать

1. На маке: `bash "win/scripts/собрать-пакет-на-маке.sh"` — сложит в архив всё,
   чего нет в git (`.env`, `users.json`, `data/`, ключи туннеля).
2. Перенести архив и папку `ENSO-Nexus/Knowledge-Base` (≈673 МБ) на Windows.
3. На Windows: `git clone https://github.com/Ni1-1a/ENSO-Nexus.git` → распаковать
   архив поверх → открыть Claude Code в этой папке → вставить промт из
   [ПРОМТ-для-вставки.txt](ПРОМТ-для-вставки.txt).
4. Claude по промту доустановит недостающее, поправит три места в коде, поднимет
   сервер и туннель и пройдёт [4-ЧЕКЛИСТ.md](4-ЧЕКЛИСТ.md).

## Скрипты (`win/scripts/`)

| Скрипт | Что делает |
|---|---|
| `собрать-пакет-на-маке.sh` | **запускается на маке**: собирает переносимый пакет |
| `install.ps1` | проверяет и ставит зависимости на Windows, `npm ci`, Chromium для Playwright |
| `start.ps1` | сервер + туннель + watchdog (замена `scripts/serve-public.sh`) |
| `stop.ps1`, `restart.ps1` | остановка и полный перезапуск |
| `health.ps1` | быстрые проверки: сервер, туннель, модель, внешний адрес |
| `Запустить сервер.bat` и др. | те же действия двойным кликом (замена папки `Перезапуск/`) |

> **Честно про статус скриптов.** Они написаны на маке и на Windows не
> запускались — проверить их отсюда нечем. Промт прямо требует от Claude на
> Windows прогнать каждый и починить на месте, а не докладывать «готово».

## Два правила, которые дороже всего стоят при ошибке

1. **Туннель работает только на ОДНОЙ машине.** Если `cloudflared` поднят и на
   маке, и на Windows, Cloudflare раскидывает запросы между ними по кругу:
   человек попадает то в одну базу, то в другую. Сначала останавливаем мак —
   `bash scripts/serve-public.sh stop` — и только потом запускаем Windows.
2. **`.env`, `users.json` и `data/` в git не уезжают** (так в `.gitignore`) —
   в них ключи API и список людей платформы с ФИО и адресами. Переносить их
   только вручную, архивом на носителе.
