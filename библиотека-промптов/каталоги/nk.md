## 3. Замечания

1. **Дубли внутри группы.** 15 мини-промптов ОВВК (nk-ovvk-01…15) и главный nk-ovvk-standards-normokontrol — одни и те же 15 проверок: блок ШАГИ главного промпта конспектирует мини-промпты. Это авторская пара «по одной / за один прогон», не ошибка извлечения. Также nk-ovvk-03-elektropitanie — укороченный вариант nk-ov-eo-sverka-elektropitanie (промпт дня 04.06 развивает проверку 03 из чек-листа 02.06).
2. **Пересечение без дубля.** nk-protokol-b2-aktualnost-ssylok и nk-sbor-ssylok-normativy решают смежную задачу противоположно: Б.2 просит модель оценить актуальность ссылок по приложенной нормативной базе, а блок из пособия по ГОСТ 21.002 прямо запрещает модели проверять редакции (это зона «только человек»). Выбирать по принятой методике; для Enso-nexus безопаснее второй подход. Проверка nk-ovvk-14 — та же тема в укороченном виде.
3. **Артефакты извлечения (исправлены с проверкой по исходным PDF).** В пяти промптах ПЗУ текстовый слой PDF содержит дублирование «Действуй как Действуй как» (метка поля + начало текста) — в файлах оставлено одно «Действуй как». В PromptdnyaOVEO04062026.pdf нумерация ШАГИ извлекается как «0» (декоративные кружки 01–04) — восстановлена как 1–4. Переносы строк внутри абзацев склеены, колонтитулы удалены.
4. **Особенности источников, оставленные дословно.** В nk-kzh-normokontrol и nk-km-normokontrol сокращение «зафикс. модель и дату» — так в PDF. В nk-pos-filtry-nakhodok и nk-pos-chetyre-rezhima строка «Источник промпта: @ai_prompt_eng» — внутри копируемого блока, сохранена. В nk-razdel9-pb-razrabotka финальная строка «Промпт подготовлен для модели Claude Sonnet 4.6 (Anthropic) | 2025» сохранена.
5. **Промпт-кейс.** nk-razdel9-pb-razrabotka содержит вшитые исходные данные конкретного объекта (школа на 1100 учащихся) — для другого объекта раздел 3 «Исходные данные» заменяется целиком; это отмечено в поле inputs.
6. **Включение вспомогательного блока.** В nk-iskhodnye-dannye-komplektnost вслед за промптом включена авторская таблица «Привязка по разделам — что добавить в Контекст» (АР/КЖ/ОВ+ВК/ПЗУ): без неё промпт не параметризуется под раздел.
7. **Нечитаемых мест не обнаружено**; pdftotext -layout дал читаемый текст по всем 11 файлам, точечная пере-экстракция (-raw) понадобилась только для проверки двух артефактов из п. 3.
