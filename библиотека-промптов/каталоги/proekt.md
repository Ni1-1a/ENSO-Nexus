## 2. Не-промптовые материалы

### P1 — Posobie_proektirovshchika_2026_1.pdf
- **Часть 0 «Закадровая подготовка документов»** — регламент подготовки входа: обезличивание по 152-ФЗ (что заменять и чем), проверка текстового слоя PDF/OCR, нарезка больших файлов, качество чертежей. Пригодность для Enso-nexus: **высокая** — готовый чек-лист предобработки документов перед загрузкой в конвейер проверки ПД/РД; правила обезличивания напрямую применимы к облачной части платформы.
- **Часть 0 «Какая модель под какую задачу»** — методика выбора модели по трём осям (контур данных/152-ФЗ, тип задачи, длина контекста) с картой решений. Пригодность: **средняя** — полезна как логика маршрутизации задач между моделями платформы (локальные / РФ-облако / зарубежные), без привязки к конкретным моделям.
- **Методология STANDARDS** — описание семиблочной структуры промпта ([РОЛЬ]…[ОГРАНИЧЕНИЯ]). Пригодность: **средняя** — шаблон для генерации собственных проверочных промптов платформы.
- **Часть 05 «Матрица типичных замечаний экспертизы»** — 8 кластеров замечаний с привязкой к задачам АР/КЖ/ОВ/ПЗУ. Пригодность: **высокая** — готовая рубрикация дефектов для классификатора замечаний нормоконтроля.
- **Часть 06 «Граница ответственности проектировщик ↔ ГИП»** — таблица, кто закрывает какое решение. Пригодность: **низкая/справочная** — полезна для маршрутизации замечаний по ролям.
- **Часть 07 «Сценарии применения»** — 5 иллюстративных сценариев «было → стало». Пригодность: **низкая** — маркетинговое/обучающее.
- **Часть 08 «Рабочие шаблоны команды»** — 5 форм-таблиц: карточка задачи, чек-лист подготовки документов, чек-лист проверки промпта, таблица запроса смежнику, шаблон письма с промптом. Пригодность: **средняя** — формы «карточка задачи» и «таблица запроса смежнику» можно превратить в структуры данных платформы.
- **Часть 09 FAQ** — 10 вопросов-ответов о применении ИИ в проектной организации. Пригодность: **низкая** — обучающее.
- **Справочник «Источники и верификация»** — таблица официальных источников нормативной базы (Минстрой, ФАУ «ФЦС», ГГЭ, ФГИС ЦС, Росстандарт, Техэксперт, КонсультантПлюс). Пригодность: **высокая** — список источников для модуля верификации ссылок на СП/ГОСТ.
