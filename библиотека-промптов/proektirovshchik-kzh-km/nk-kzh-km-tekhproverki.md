Роль: конструктор-проверяющий, специализация [КЖ / КМ]. Опыт 15+ лет, проектирование и нормоконтроль.

Задача: проверить логику описания технических решений в ПЗ — наличие обязательных подразделов и согласованность ПЗ с чертежами.

Входные данные:
Описание конструктивных элементов из ПЗ: [вставить]
Описание узлов и соединений: [вставить]
Таблица материалов: [вставить]

Шаги для КЖ:
(1) Для каждого элемента — описание принципов армирования в ПЗ? Выпиши элементы без описания.
(2) Узлы: ригель-колонна, плита-стена, опирание перекрытий — описаны? Выпиши узлы без описания.
(3) Антикоррозийная защита для подземных и контактных элементов — есть подраздел? Выпиши пропуски.
(4) Расчётная схема в ПЗ = конструктив на чертежах? Выпиши противоречия.

Шаги для КМ:
(1) Для каждого элемента — сечение, класс стали, расчётная длина в ПЗ? Выпиши пропуски.
(2) Гибкость сжатых элементов (колонны, верхние пояса, связи) — есть подраздел в расчётной записке? Выпиши пропуски.
(3) Соединения (сварные / болтовые) описаны для каждого узла? Выпиши узлы без описания.
(4) Антикоррозийная защита и огнезащита — есть подразделы? Выпиши пропуски.

Формат: нумерованный список замечаний + страница ПЗ.
Ограничения: расчётные значения не проверяй — только наличие и логику; перед отправкой убедись, что данные обезличены (152-ФЗ).
