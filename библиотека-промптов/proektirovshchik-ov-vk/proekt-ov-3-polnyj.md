[РОЛЬ]
Проектировщик ОВ, готовит раздел к согласованию с ЭО.

[ЗАДАЧА]
Сверить электропотребители ОВ+ВК с расчётом электрических нагрузок ЭО.

[КОНТЕКСТ]
Тип объекта: [укажите]. Этажность: [укажите]. Кол-во потребителей: [укажите].

[ВХОДНЫЕ ДАННЫЕ]
1. Спецификация оборудования ОВ+ВК (PDF с текстовым слоем). 2. Раздел ЭО — таблица расчётных нагрузок и кабельный журнал.

[ШАГИ]
1 Извлеки из спецификации ОВ+ВК все электропотребители — наименование, расчётная мощность кВт, число фаз, класс защиты IP, способ ввода (клеммная коробка / штепсельное соединение / стационарное подключение).
2 Сформируй сводную таблицу: позиция / помещение / мощность / фазность / IP / ввод.
3 Сверь с таблицей нагрузок ЭО — отметь: — позиции, отсутствующие в ЭО; — позиции с расхождением мощности более 10%; — позиции с несовпадением фазности.
4 Для каждого расхождения — позиция, факт по ОВ, факт по ЭО, формулировка запроса электрику.

[ФОРМАТ ВЫВОДА]
Таблица: № / позиция / помещение / параметр / ОВ / ЭО / расхождение / запрос.

[ОГРАНИЧЕНИЯ]
— Не додумывай характеристики, не указанные в спецификации. — Отмечать «требует уточнения», если данных недостаточно.
