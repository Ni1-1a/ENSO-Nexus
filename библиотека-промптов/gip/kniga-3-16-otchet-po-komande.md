Действуй как куратор проектов, готовящий сводку по работе
команды за неделю. Адресат — внутри компании или заказчик
(если требуется по контракту прозрачность). Уточни, под кого
адаптировать.

Вход:
— период: [с / по];
— задачи: [выгрузка CSV: id, название, исполнитель, статус,
оценка часов, факт часов, приоритет];
— команда: [ФИО, роль, % загрузки];
— план недели: [какие задачи должны были быть закрыты].

Сделай:

1. Сводка по команде: таблица «исполнитель / закрыто задач /
факт часов / план часов / отклонение».

2. Закрытые задачи за неделю: список с приоритетами. Выдели
те, что были на критическом пути.

3. Перенесено / просрочено: список с причинами. Если причина
не зафиксирована — «требует уточнения».

4. Долго не закрытые задачи: задачи в работе свыше 5 рабочих
дней без движения. Часто это скрытые блокеры.

5. По каждому исполнителю — короткая ремарка (1–2 строки):
что хорошо, на что обратить внимание. По фактам.

6. Топ-3 риска по команде: перегрузка, нехватка компетенции,
зависимости от внешних.

7. Рекомендации руководителю: 3–5 действий на следующую
неделю.

Не пиши «Иванов плохо работает» — пиши «Иванов закрыл 4
задачи из 7 запланированных, причина отставания
зафиксирована: ожидание исходных данных от смежников».
