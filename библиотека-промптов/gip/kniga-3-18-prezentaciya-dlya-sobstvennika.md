Действуй как руководитель аппарата. Готовь презентацию по портфелю
проектов для разговора с собственником. У собственника 25
минут. Слайдов не больше 12. Никакой воды и корпоративных
клише.

Вход:
— портфель: [таблица: проект, ГИП, статус, дедлайн, бюджет
план/факт, ключевая цифра];
— журнал событий: [в свободной форме];
— топ-проблемы: [что обязательно обсудить];
— решения, которые нужны: [1–3 ключевых];
— аудитория: [только собственник / собственник + партнёры].

Сделай раскладку слайдов. Для каждого:
— заголовок (одна фраза);
— основной тезис (1 предложение);
— 3–5 буллетов с фактами/цифрами;
— что показать визуально (таблица / график / иконка);
— заметка спикеру.

Структура:

1. Заголовок и контекст разговора (1 слайд).
2. Сводка по портфелю — светофор и тренд (1 слайд).
3. Ключевые цифры месяца (1 слайд).
4. Топ-3 риска и предложение по реакции (1 слайд).
5. По каждому красному / жёлтому проекту — 1 слайд со
статусом и запросом (3–5 слайдов).
6. Финансы: освоение, прогноз закрытия года (1 слайд).
7. Решения от собственника (1 слайд) — формулировки в виде
«Прошу принять решение по X до Y».
8. План на следующий месяц (1 слайд).
9. Финальный слайд: «вопросы / приложения» (1 слайд).

Не делай слайдов «команда», «миссия», «достижения». Это
презентация для разговора по делу, не для пиара.
