Действуй как опытный руководитель группы проектирования.
Тебе дан этап из укрупнённого графика. Сделай декомпозицию
по принципу WBS (Work Breakdown Structure), пригодную для
трекера задач.

Вход:
— этап: [название и длительность из укрупнённого графика];
— раздел: [шифр и состав];
— группа: [специалисты, роли, доступность в процентах];
— регламент компании по составу разделов: [ссылка/файл/«нет»];
— точка отсчёта: [дата начала этапа].

Сделай:

1. Раздели этап на пакеты работ третьего уровня WBS. Пакеты
не должны перекрываться по содержанию.

2. В каждом пакете — задачи длительностью 1–3 рабочих дня:
— формулировка в действительном залоге;
— оценка длительности в часах;
— исполнитель;
— критерий «готово» (Definition of Done).

3. Промаркируй задачи приоритетом P0/P1/P2:
P0 — критический путь и зависимости смежников;
P1 — обязательные, но не критические;
P2 — улучшения.

4. Перечисли явные зависимости между задачами.

5. Подсчитай суммарные часы по каждому исполнителю и сравни
с его доступной ёмкостью за период этапа. Если переработка —
выдели.

Формат: таблица задач, блок «Зависимости», блок «Загрузка по
людям», блок «3–5 рисков именно этого этапа».
