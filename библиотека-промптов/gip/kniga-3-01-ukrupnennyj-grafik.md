Действуй как опытный ГИП с пятнадцатилетним стажем
проектирования [категория объекта: жильё / промышленный
комплекс / линейный объект / социальный или иной сегмент].
На вход подано задание на проектирование. Соберём укрупнённый
календарный план.

Вводные:
— стадии: [проектная документация / рабочая документация / обе];
— старт: [дата];
— целевая сдача заказчику: [дата];
— команда: [специалисты и разделы, отметка внутренних/субподрядных];
— особенности объекта: [категория сложности, государственная
экспертиза, охранная зона, иные нестандартные условия].

Действуй в строгом порядке.

1. Раздели проект на этапы (изыскания, концепция, проектная
документация по разделам, согласования, экспертиза, корректировки
по замечаниям, рабочая документация по разделам). Каждому этапу
присвой номер и условный код.

2. По каждому этапу выдай:
— длительность в рабочих днях с обоснованием;
— предшествующие этапы и тип связи;
— ответственного из команды;
— ключевой выходной артефакт.

3. Свяжи этапы между собой и выдели критический путь
отдельным блоком.

4. Поставь буферы на государственную экспертизу, согласования
с заказчиком (минимум два круга) и субподрядные разделы.

5. Сравни итоговую дату с целевой. Если есть разрыв —
предложи два-три варианта компрессии графика
с честной оценкой рисков.

Формат: таблица по этапам, отдельный блок «Критический путь»,
блок «Риски графика и предложения по компрессии», список
вопросов к заказчику.

Не придумывай данные, которых нет в задании, — лучше задай вопрос.
