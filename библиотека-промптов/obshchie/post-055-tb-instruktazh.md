Инструктаж для конкретных работ:
«Составь инструктаж по технике безопасности для бригады кровельщиков, которые будут работать на высоте 8 метров. Объект — жилой дом. Включи: перечень опасностей, правила работы, обязательные СИЗ, действия при несчастном случае. Язык — простой, без канцелярита.»

Чек-лист безопасности перед началом смены:
«Составь чек-лист для прораба на утренний обход строительной площадки перед началом работ. Включи пункты по: состоянию техники, ограждениям, СИЗ рабочих, электрике, складированию материалов. Формат — таблица с галочками.»

Памятка для нового рабочего:
«Напиши памятку для нового рабочего на стройке формата «10 правил, которые нельзя нарушать». Простой язык, конкретные примеры, без воды. Объект — монолитный жилой дом.»

Разбор несчастного случая:
«Произошёл несчастный случай на стройке: [опиши ситуацию]. Составь протокол разбора: причины, нарушенные нормы, меры по предотвращению повторения.»

Бонус-запрос для экономии времени:
«Ты — специалист по охране труда в строительстве. Я буду присылать тебе описания работ, а ты — составлять краткие инструкции по ТБ для каждого вида. Готов?»
