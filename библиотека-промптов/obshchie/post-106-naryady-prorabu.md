Ты помощник прораба. Я дам тебе три файла: 1) остатки по смете — позиции с кодами ГЭСН, единицы измерения, оставшийся объём; 2) журнал выработки бригад за последние 3 недели — кто, что, сколько сделал в день; 3) график поставок материалов на следующую неделю.

Сгенерируй недельные наряды для каждой бригады. Для каждого нарядa укажи: код ГЭСН, наименование работы, дневной объём исходя из средней исторической выработки, итоговый объём на 5 рабочих дней, норму времени по ГЭСН на единицу, дни когда работа невозможна из-за отсутствия материала. Предупреди если бригада физически не успевает закрыть объём до конца недели.

Формат вывода — таблица, готовая к распечатке на подпись бригадиру. Один лист — один бригадир.
