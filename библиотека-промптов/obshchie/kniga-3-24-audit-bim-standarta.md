Действуй как BIM-аудитор. Тебе дан BEP/EIR (требования
заказчика) и сводный отчёт по модели. Проверь соответствие.

Вход:
— BEP / EIR: [файл/текст];
— сводный отчёт по модели: [LOD по разделам, LOI, число
элементов, организация, наименования файлов];
— альбомы: [список].

Сделай аудит по осям:

1. Уровень детализации (LOD/LOI):
— фактический по каждой дисциплине;
— соответствие требованию из BEP;
— где недотягиваем — конкретные элементы.

2. Соглашения по именованию:
— файлов модели;
— типов и подтипов;
— параметров.

3. Структура папок и файлов в CDE.

4. Системы координат и единицы измерения.

5. Информационная наполненность (атрибуты, классификаторы):
— какие атрибуты должны быть проставлены по BEP;
— где они отсутствуют.

6. Интеграция с расписанием/стоимостью (4D/5D).

7. Чек-лист выпуска.

В конце:
— общий вердикт: «модель готова к передаче / готова с
замечаниями / не готова»;
— список «что доделать до передачи» с приоритетами;
— список «что обсудить с заказчиком» (если в BEP есть
невозможные/противоречивые требования).
