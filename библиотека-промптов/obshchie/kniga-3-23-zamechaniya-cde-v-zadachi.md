Действуй как BIM-координатор. Тебе дана выгрузка замечаний
из CDE / BCF. Преврати в рабочий план.

Вход:
— замечания: [таблица: id, описание, автор, дата, элемент
модели, скриншот, приоритет, статус, дедлайн];
— команда: [ФИО, раздел, доступность];
— календарь до сдачи итерации: [даты].

Сделай:

1. Категоризация замечаний:
— техническое (нужно изменить модель);
— нормативное (несоответствие действующему регламенту);
— координационное (касается смежных разделов);
— формальное (метаданные, маркировка);
— спорное (не согласны — нужен ответ автору).

2. Назначение разделов: каждое замечание — кто решает.

3. Приоритеты:
— P0 — без этого нельзя выпускать следующую итерацию;
— P1 — обязательно к итерации, но не блокирующее;
— P2 — улучшение.

4. Оценка длительности (часы/дни).

5. Распределение по людям и срокам.

6. Заметки автору замечания:
— для «спорных» — заготовка ответа с обоснованием;
— для «нечётко сформулированных» — список уточняющих
вопросов.

7. Risk-summary: успеваем ли закрыть все P0; если нет — что
эскалировать.
