# Библиотека промптов канала «AI песочница инженера»

416 верифицированных владельцем промптов для инженерных задач (нормоконтроль,
сметы, ПТО, ГИП, заказчик), перенесённых из Telegram-канала @ai_prompt_eng.

Источник — экспорт канала из Telegram Desktop от 27.08.2026
(`~/Downloads/Telegram Desktop/ChatExport_2026-08-27`): 302 поста
14.01–27.08.2026 и 81 вложение, плюс два файла из комментариев, переданные
владельцем отдельно 27.08.2026. Это «второй проход по вложениям» из
`нормоконтроль/decisions/open-questions.md` → OQ-05 (решение от 24.08.2026);
первый проход 24.08.2026 разбирал только тексты постов
(`нормоконтроль/decisions/prompt-techniques-review.md`).

## Что это и что это НЕ

- Это **данные, а не код**: библиотека готовых текстов запросов для человека
  и для функции автоматического подбора промпта под загруженный документ.
- Каталог `prompts/` в корне проекта сюда НЕ относится: те файлы читает
  `server/services/prompts.js`, и тест требует соответствия «файл ↔ вызов
  в коде».
- Тексты перенесены **дословно** (промпты верифицированы владельцем);
  вычищены только артефакты извлечения из PDF — переносы слов, колонтитулы,
  номера страниц. Найденные опечатки исходника сохранены и описаны
  в `каталоги/*.md`.

## Формат файла

```
---
id / title / role / section / kind (полный|быстрый|сверка|запрос|другое)
task / inputs / source_file / source_post
---
дословный текст промпта
```

Префикс id = источник: `proekt-` (Пособие проектировщика + АР), `nk-`
(чек-листы и нормоконтроль), `smeta-`, `ptg-` (ПТО/ГИП/внедрение), `kniga-`
(Большие книги 1–3), `extra-` (заказчик, регламенты, экспресс-гайды),
`post-` (промпты из текстов постов), `dop-` (доборы из комментариев канала).

## Дубли

Книги 1–3 (апрель–май) частично вобраны позднейшими пособиями. Дубли НЕ
удалялись — обе редакции имеют provenance; уверенные пары помечены в
`каталоги/kniga.md` (колонка «возможный дубль»), пересечения внутри групп —
в «Замечаниях» каталогов. При выдаче пользователю предпочитать версию из
пособий (позднее = отредактированное).
