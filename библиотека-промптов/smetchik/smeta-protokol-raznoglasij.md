Действуй как инженер-сметчик / руководитель сметной службы.
С подрядчиком есть разногласия по смете.

Вход:
— Список спорных позиций
— описание позиции каждой стороны.

Сделай:
1. По каждой позиции: «Наша редакция | Обоснование | Редакция подрядчика | Обоснование | Итоговая редакция».
2. Тон — нейтральный, инженерный.
3. Обоснования — со ссылкой на нормативные документы (Методика 421/пр, актуальные документы ФРСН) или условия договора.

Формат: Markdown-таблица «Протокол разногласий» по позициям.

Ограничения:
— Не делать вывод о «правильной» редакции.
— Обоснования — фактические, без оценок.

Самопроверка: Указать, по каким позициям обоснования сторон слабые.
