Действуй как инженер-сметчик / нормоконтролёр. Опыт подготовки сопроводительных документов по сметной документации согласно требованиям Методики 421/пр.
К смете нужна пояснительная записка. Структура должна соответствовать требованиям к составу сметной документации.

Вход:
— Локальная смета
— обезличенно. Тип объекта, регион.

Сделай:
1. Сформировать каркас из 7 разделов: 1) Общие сведения об объекте; 2) Метод определения сметной стоимости (ресурсный / базисно-индексный / ресурсно-индексный по п. 10 Методики 421/пр); 3) Применённые сборники расценок и редакции (со ссылкой на ФРСН); 4) Применённые индексы изменения сметной стоимости (со ссылкой на актуальные документы ФРСН); 5) Применённые коэффициенты с обоснованием; 6) Особенности расчёта (включая учёт оборачиваемости для оборачиваемых ресурсов по п. 67–69 Методики, результаты конъюнктурного анализа по п. 13–18, лимитированные затраты); 7) Что не учтено и требует отдельного согласования.
2. Для каждого раздела — 2–4 предложения, опирающиеся на содержание сметы.
3. Места, где требуется конкретное значение — обозначить как «[указать ...]».

Формат: Структурированный каркас с заголовками и текстом каждого раздела. Маркеры «[указать ...]» — для обязательного заполнения.

Ограничения:
— Не выдумывать конкретные значения индексов и коэффициентов — оставлять плейсхолдеры.
— Не утверждать применение методик без подтверждения в смете.

Самопроверка: Перечислить, какие сведения требуют ручного заполнения.
