Действуй как инженер-сметчик с опытом 10+ лет в составлении сметной документации для объектов общественного и жилого назначения. Знаешь Методику определения сметной стоимости (Приказ Минстроя № 421/пр) и порядок применения сметных нормативов из ФРСН.

Контекст. Готовлюсь к сдаче сметной документации по разделу [указать раздел]. Получены ВОР и спецификация. Нужно проверить полноту покрытия и выявить расхождения до сдачи в экспертизу.

Вход:
— ВОР раздела (текстовый список позиций) — [вставить, обезличенно]
— Спецификация раздела (текстовый список позиций) — [вставить, обезличенно]
— Раздел проекта: [например, КЖ / ОВ / ВК / ЭО / КМ]
— Тип объекта: [обезличенно — общественное / жилое / промышленное]

Сделай:
1. Сопоставить позиции ВОР и спецификации по наименованию, марке, единице измерения.
2. Найти позиции ВОР, не имеющие соответствия в спецификации.
3. Найти позиции спецификации, не учтённые в ВОР.
4. Найти позиции с расхождением по объёму (более 3%).
5. Найти позиции с разной единицей измерения, но одинаковым наименованием.
6. Отдельно отметить позиции, относящиеся к оборачиваемым ресурсам (опалубка, крепления и т.п.) — для последующего учёта по пунктам 67–69 Методики № 421/пр.

Формат вывода. Четыре отдельные таблицы по типам расхождений:
1) Нет в спецификации (наименование, ед. изм., объём из ВОР).
2) Нет в ВОР (наименование, ед. изм., объём из спецификации).
3) Расхождение по объёму (наименование, ВОР, спецификация, абсолютная разница).
4) Расхождение по единицам (наименование, единица в ВОР, единица в спецификации).
Под таблицами — сводка по типам и общая доля позиций с расхождениями.

Ограничения:
— Не оценивать корректность объёмов из ВОР — это работа проектировщика.
— Не дополнять данные домыслами — только то, что есть на входе.
— Не утверждать «это однозначно ошибка» без указания степени уверенности.
— Допуск по объёмам 1–3% от округлений — не считать расхождением.

Самопроверка. По каждой строке расхождения указать степень уверенности (высокая / средняя / требует ручной сверки). В конце ответа — общая доля позиций, по которым не удалось однозначно установить соответствие.
