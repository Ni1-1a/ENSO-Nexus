Действуй как инженер-сметчик / руководитель сметной службы.
По объекту прошло 15+ замечаний экспертизы. Нужен сводный реестр.

Вход:
— Список замечаний и черновики ответов
— обезличенно.

Сделай:
1. Свести в таблицу: № / суть / наш ответ / статус.
2. Подсчитать сводку: всего / закрыто / в работе / спорные.
3. По спорным позициям — резюме позиции каждой стороны.
4. Вывод 3 строки: какие тренды видны.

Формат: Markdown-таблица + сводка + вывод.

Ограничения:
— Не делать вывод о виновности.
— Резюме спорных позиций — нейтральное.

Самопроверка: Указать, какие позиции требуют дополнительных данных для разбора.
