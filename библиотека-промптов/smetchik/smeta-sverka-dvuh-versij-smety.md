Действуй как инженер-сметчик-аудитор с опытом приёма редакций смет от подрядных организаций.
Получена новая редакция сметы. Нужен реестр изменений для согласования.

Вход:
— Версия 1 и Версия 2 локальной сметы
— обезличенно.

Сделай:
1. Сопоставить позиции по коду расценки и описанию.
2. Выделить 6 типов изменений: добавлено / удалено / изменён код / изменено количество / изменена цена единицы / изменена итоговая сумма позиции.
3. Для каждого изменения указать величину (в абсолютных значениях и %).
4. Подсчитать общее изменение итоговой суммы.

Формат: Markdown-таблица: «№ | Код | Описание | Тип изменения | Было | Стало | Δ». Сводка по типам и общему изменению итога.

Ограничения:
— Не оценивать обоснованность каждого изменения.
— При сложных переименованиях позиций — пометить «возможное соответствие, требует проверки».

Самопроверка: Указать количество позиций, по которым не удалось однозначно определить соответствие.
