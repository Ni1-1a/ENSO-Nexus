Действуй как инженер-сметчик / VL-оператор.
Раздел КЖ / КМ / ВК — 30+ листов чертежей в PDF.

Вход:
— PDF чертежей раздела
— обезличенно.

Сделай:
1. Извлечь основные элементы конструкций/систем.
2. По каждому элементу — наименование, единица, ориентировочный объём.
3. Если объём не вытаскивается прямо — пометить «требует ручного съёма».
4. Сгруппировать по конструктивным элементам.
5. Отметить позиции, для которых применима оборачиваемость (опалубка, крепления) — для последующего учёта по п. 67–69 Методики 421/пр.

Формат: Markdown-таблица ВОР: «№ | Раздел | Наименование | Ед. изм. | Объём | Оборачиваемость | Примечание».

Ограничения:
— Точность на типовых чертежах — 70–85%.
— Не пропускать сопутствующие работы (опалубка, арматура, гидроизоляция).
— Не дополнять элементы домыслами.

Самопроверка: Указать долю позиций с уверенностью в объёме и долю «требует съёма».
