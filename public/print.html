Разбор PDF по форматам

Каждый лист комплекта меряется по геометрии страницы, определяется как формат ГОСТ 2.301-68, кратный, плюсовой или нестандарт и уходит в корзину носителя по короткой стороне: лист принтера или рулон плоттера. На каждую корзину (или на корзину тома) собирается один PDF — открыть во вкладке, напечатать или скачать. Ниже — время печати на парке принтеров, экземпляры и переплёт, нормоконтроль тома. Нейросеть не участвует.

1. Исходные PDF

Добавить PDF — или перетащите файлы и папки сюда. Загрузка начинается сразу, кусками: большие файлы проходят.

    2. Параметры

    Пределы пакета: если пакет не влезает, он делится на части «…__часть2из3.pdf» по границам страниц без перестановки листов; размер куска меряется сборкой qpdf (ресурсы у страниц общие, сумма размеров страниц неверна). Лист, который сам больше предела, выводится отдельным пакетом с предупреждением.

      Скачать и отчёт

      Экземпляры и переплёт

      Листов в томе → слоёв с учётом сложенных листов (модель ГОСТ 2.501-2013, табл. Г.2) → толщина блока → диаметр пружины по таблице поставщика. Это слои по толщине, а не приведённые листы по площади из сводки выше. Пружина выбирается по наибольшей толщине блока; поле подшивки у сложенного листа — один слой, разница даёт клин, его компенсируют вкладыши.

      Время печати

      Каждый пакет уходит только на совместимый принтер (лист помещается или рулон нужной ширины заряжен либо есть на полке). Распределение — самые долгие задания первыми на наименее загруженный принтер; смена рулона стоит времени. Накладные (прогрев, RIP, отрез) оценочные, поэтому показана вилка. После печати введите фактическое время — коэффициент принтера подстроится.

      Парк принтеров

      Общий парк офиса правит владелец платформы; личные принтеры каждый добавляет себе сам. Цифры пресетов — из паспортов производителя, ссылка в карточке.

      Нормоконтроль тома

      Детерминированные проверки без нейросети: объём тома (ГОСТ Р 21.101-2020, п. 8.1.3), графа «Листов» против фактического числа листов, подпись «Формат» под рамкой против измеренного формата, нестандартные листы, переплёт. Текст читается из пакетов разбора; скан без текстового слоя честно помечается «не проверено». Замечания — в формате модуля «Нормоконтроль».
