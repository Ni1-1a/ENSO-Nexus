Акты (АОСР)

Пачка черновиков актов из таблицы и шаблона, сверка дат актов с общим журналом. Всё считается кодом, нейросеть не участвует: данные не покидают контур

Конвейер черновиков

Раз акты отличаются только данными — заполните таблицу один раз. Пустая ячейка станет «{НЕТ ДАННЫХ}» в тексте и попадёт в отчёт пропусков; конвейер ничего не выдумывает.

Реестр данных (XLSX) — первая строка листа: заголовки колонок
Шаблон акта (DOCX) — плейсхолдеры вида {{Имя колонки}}

Сверка дат: акты ↔ общий журнал

Акт подписан 14-го, запись в журнале — 17-го: стройконтроль такое находит за один проход. Сопоставление — по совпадению формулировок вида работ; строки без пары проверяются вручную.
