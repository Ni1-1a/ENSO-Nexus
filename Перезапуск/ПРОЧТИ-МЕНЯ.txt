ENSO Nexus Pilot 1 — управление сервером
=========================================

Файлы в этой папке запускаются ДВОЙНЫМ КЛИКОМ (откроется Терминал):

  • «Запустить сервер.command»      — запуск после перезагрузки Mac.
                                       Если уже запущено — просто сообщит об этом.

  • «Перезапустить сервер.command»  — полный перезапуск (сервер + туннель + watchdog).
                                       Нужен в основном после правок файла .env
                                       (ключи API, лимиты). Если идёт анализ —
                                       предупредит и спросит подтверждение.

  • «Остановить сервер.command»     — полная остановка. Приложение станет
                                       недоступно, пока не запустите снова.

Те же команды в Терминале вручную:

  Запуск:       cd "…/ENSO-Nexus/enso-platform" && bash scripts/serve-public.sh
  Перезапуск:   cd "…/ENSO-Nexus/enso-platform" && bash scripts/serve-public.sh stop && bash scripts/serve-public.sh
  Остановка:    cd "…/ENSO-Nexus/enso-platform" && bash scripts/serve-public.sh stop

Полезно знать
-------------
• Главный адрес приложения: https://enso-nexus.com
  (https://app.enso-nexus.ru тоже работает, без редиректа; страница-вход: https://ni1-1a.github.io/ENSO-Nexus/ — покажет
  «Сервер недоступен», если Mac выключен, и сама дождётся включения).

• Перезапуск ПРЕРЫВАЕТ выполняющийся анализ — дождитесь окончания
  (видно по карточке прогресса в приложении).

• Обычно перезапуск не нужен: watchdog сам поднимает упавший сервер
  и туннель за 1–2 минуты.

• Для работы нужны: включённый Mac (скрипт не даёт ему уснуть,
  крышку не закрывать) и запущенный LM Studio (для локальной модели).

• Журналы, если что-то пошло не так: папка enso-platform/logs
  (server.log — сервер, tunnel.log — туннель, watchdog.log — надзор).

Если файл .command не запускается двойным кликом (macOS может спросить
разрешение при первом запуске): правый клик → «Открыть» → «Открыть».
